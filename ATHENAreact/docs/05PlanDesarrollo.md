# Documento 05 - Plan Oficial de Desarrollo

Versión: 1.0

Proyecto: ATHENA

---

# Objetivo

Organizar el desarrollo del proyecto para evitar conflictos entre los integrantes del equipo.

Cada tarea tendrá un responsable, una prioridad y dependencias.

---

# Metodología

Se trabajará por módulos.

Cada módulo deberá seguir este flujo:

1. Analizar documentación.
2. Diseñar.
3. Backend.
4. Frontend.
5. Integración.
6. Pruebas.
7. Documentación.

Ningún módulo se considerará terminado hasta completar los siete pasos.

# Definición de Terminado

Una tarea estará terminada únicamente cuando:

✓ Funcione correctamente.

✓ No tenga errores.

✓ Esté integrada.

✓ Esté documentada.

✓ Haya sido probada.

---

# Reglas

No programar fuera del sprint actual.

No modificar otro módulo sin autorización.

No subir código sin probar.

Toda nueva funcionalidad deberá actualizar la documentación.
